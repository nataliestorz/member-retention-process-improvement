# Business Process Improvement: Member Retention

## Overview

This project applied Lean Six Sigma (DMAIC) methodology to analyze and improve the member retention process of a collegiate membership organization.

The objective was to identify the primary drivers of member attrition and recommend data-driven process improvements to increase long-term retention.

---

## Business Problem

The organization experienced approximately **20% member attrition before graduation**, affecting leadership continuity, member engagement, and organizational stability.

This project sought to answer:

- Why are members leaving?
- Where does attrition occur?
- Which process failures contribute most?
- What improvements should be implemented?

---

## Methodology

This project followed the DMAIC framework:

- Define
- Measure
- Analyze
- Improve
- Control
